# borekiller-Side quest geneartor
A side quest generator that takes given quests divided in different categories (Mind, Body and Social) and difficulties(Easy, Mid and Hard) and
give the user some quest based on some questions answered before

## How it Works:

Run the program and choose one category:

- Mind: Mental challenges
- Body: Physical challenges
- Social: Improvins social-skills
- Random: Get a random one

Then choose a difficulty:

- Easy
- Mid
- Hard
